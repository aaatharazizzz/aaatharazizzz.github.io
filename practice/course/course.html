HTML

The skeleton of a website.

HTML, or HyperText Markup Language, is a markup language that allows you to create structure and content for your website.

CSS

The style of a website.

CSS, or Cascading Style Sheets, is a styling language that allows you to design the look of your website.

Javascript

The scripting language of a website.

Javascript, or JS for short, is a scripting language that allows you to create interactive and dynamic websites.

PHP

The backend language of a website.

PHP is a server-sided scripting language that allows you to create interactive and dynamic websites from the backend.
